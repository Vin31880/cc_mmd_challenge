Place the four official CC-MMD 2026 test-label files here:

    MDMD_Tamil_test_labelled.csv
    MDMD_Malaylam_test_labelled.csv
    CMMD_test_labelled.csv
    MAMI_test_labelled.csv

They are not redistributed in this repository (see the Data section of the README).
Each file must contain an `image_id` column and the label columns for that corpus
(`original_labels`, `irish_labels`, and `chinese_labels` or `indian_labels`), with
values `misogyny` / `not-misogyny`.
